# Citing SonoSK

If SonoSK is used in published work, please cite the software. The
citation details are in the file `CITATION.cff` at the top of the
repository, and the "Cite this repository" button on the GitHub page gives
them in APA and BibTeX form.

Every release is archived on Zenodo with its own DOI. Cite the DOI of the
version you used, so that others can reproduce the results with the same
code.

In the methods section, please give the SonoSK version
(`sonosk.__version__`), the transducer and medium parameters, the grid
spacing and, for imaging, the scatterer density and the transmit sequence.
A script that reproduces the figures is the best record of all of these.
